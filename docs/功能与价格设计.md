## 2. 定价建议（两套方案）

### 背景参考
同类个人开发者制品在内容平台常见"¥30 源码买断"的一口价模式：低价走量、一次性交付、无后续服务。本方案在此基础上补一档可持续收入。

### 方案 A：买断制（对标 ¥30 模式，适合个人/小团队尝鲜）

| 版本 | 价格 | 说明 |
|---|---|---|
| 社区版源码 | **¥0**（开源引流） | GitHub 开源，获客与口碑 |
| 标准版源码买断 | **¥99** | 买断当前大版本，含部署文档 |
| 企业版源码买断 | **¥599** | 含 LDAP/SSO、多数据源、私有化支持（远程协助 1 次） |

**定价理由**：¥30 档只能覆盖"代码本身"，无服务、无更新；¥99 锚定"一次付费、解决问数刚需"，仍远低于企业 BI 采购门槛；企业版 ¥599 对标一次咨询半天费用，用"私有化+合规审计"支撑溢价。

### 方案 B：订阅制（可持续收入，推荐主推）

| 版本 | 价格 | 说明 |
|---|---|---|
| 标准版 | **¥29/月** 或 ¥299/年 | 按月付降低决策门槛 |
| 企业版 | **¥199/月** 或 ¥1999/年 | 含 SSO、多数据源、SLA |

**定价理由**：大模型调用是持续成本，订阅制才能覆盖 token 与运维；¥29/月 ≈ 一杯咖啡，对标"HR 每月省 10+ 小时取数"的价值感知；年付 8.5 折促进续费。买断与订阅可并存：买断卖"当下"，订阅卖"持续省心"。

### 建议组合打法
1. 社区版开源 → 内容平台（小红书/掘金）发"HR 问数"演示视频引流；
2. 标准版 ¥99 买断承接"想自己搭"的个人与小公司；
3. 企业版走订阅，做 3–5 家种子客户打磨 SSO 与多数据源。

## 3. 交付形态（三选）

| 形态 | 做法 | 适合 | 成本 |
|---|---|---|---|
| **源码交付** | 打包 backend/ + frontend/ + docs，买家自备服务器 | 个人开发者转售、¥99 买断 | 最低 |
| **Docker 一键部署** | 本仓库 docker-compose.yml：api + web + 数据卷，`docker compose up -d` 即用 | 中小企业私有化 | 一次打包 |
| **SaaS 化** | 多租户改造（租户 ID 隔离）+ 按量计费 + 官网 | 订阅制主推 | 需持续运维 |

**MVP 建议**：先以"源码 + Docker"交付跑通前 20 个付费用户，验证需求后再投入 SaaS 多租户改造成本。

## 4. 成本与毛利速算（标准版订阅）

- 大模型成本：单次问数约 2k–4k tokens，按 DeepSeek 现价约 ¥0.003–0.01/次；1000 次/月 ≈ ¥10；
- 服务器：2C4G 云主机约 ¥60/月，可承载数十家小客户（SQLite 阶段）；
- ¥29/月 × 100 付费用户 = ¥2900/月，毛利约 90%+。规模上去后切 PG 与对象存储。
