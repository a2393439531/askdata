# 员工问数 AI 智能体 · 实施步骤

> 从零到可运行的分步操作。默认在 Linux / macOS 终端执行，Windows 请用 PowerShell（命令基本一致）。

---

## 0. 环境要求

- Python 3.10+（后端）
- Node.js 18+（前端，可选：只跑后端演示可跳过前端）
- Docker（可选：用 docker-compose 一键拉起，见 §4）

---

## 1. 后端启动（FastAPI + SQLite）

```bash
cd ~/workspace/hr-insight-ai/backend

# 1) 创建虚拟环境并安装依赖
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2) 配置环境变量（复制模板后填写）
cp .env.example .env
# 用编辑器打开 .env，按需填写大模型 Key（不填也能跑，问数走模板匹配）

# 3) 初始化数据库 + 演示数据（员工/薪资/考勤/绩效/模板/账号）
python -m app.seed

# 4) 启动服务（首次启动会自动建库+灌数据，可跳过第 3 步）
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

打开 http://localhost:8000/docs 查看自动生成的 API 文档。

**测试账号**（密码均为 `Admin@2024`）：`superadmin` / `hradmin` / `techadmin` / `operator01` / `auditor`

## 2. 前端启动（Vue3，可选）

```bash
cd ~/workspace/hr-insight-ai/frontend
npm install
npm run dev        # 开发模式 http://localhost:5173（已代理 /api 到 8000）
# 或构建后由后端托管：
npm run build
```

## 3. 后端自测

```bash
cd ~/workspace/hr-insight-ai/backend
source .venv/bin/activate
pytest tests/ -v
```

自测覆盖：登录成功/失败、问数（模板匹配路径）、模板执行、CSV 导出、越权访问拦截、审计日志写入。

也可以用 curl 快速验证：

```bash
TOKEN=$(curl -s -X POST http://localhost:8000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"superadmin","password":"Admin@2024"}' | python3 -c "import sys,json;print(json.load(sys.stdin)['access_token'])")

curl -s -X POST http://localhost:8000/api/chat/ask \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"question":"各部门有多少员工？","model":"deepseek"}' | python3 -m json.tool | head -30
```

## 4. Docker 一键部署（可选）

```bash
cd ~/workspace/hr-insight-ai
docker compose up -d --build
# 前端 http://localhost:3000，后端 http://localhost:8000
# 大模型 Key 通过环境变量 LLM_DEEPSEEK_API_KEY / LLM_QWEN_API_KEY 传入
```

## 5. 常见问题

| 现象 | 排查 |
|---|---|
| 问数返回"未配置大模型" | .env 里没填 Key，走模板匹配是正常的；或直接点"问题模板"执行 |
| 前端 401 跳登录 | token 过期（8h）或账号被禁用，重新登录 |
| 端口被占用 | 改 `--port`，前端 vite.config.js 同步改 proxy |
| SQLite 被锁 | 单进程 uvicorn 不要开 --workers 多进程（演示库限制） |
